# 学习笔记模板

> 这份笔记的作用：把你看过的东西，变成你自己的话。以后问 OKS 时，它靠这些笔记回答你。
> 先看右边（或下面的）例子，再照着填。

## ① 先看一个填好的例子

以一篇讲 AI 记忆的文章为例：

```markdown
# 学习笔记：AI Agent 的记忆体系

## 我学了什么

这篇文章讲 AI Agent 怎么记住长期信息——分短期工作记忆、长期知识、可被检索的外部知识库三层。

## 我记下的要点

1. AI 记忆分三层：短期工作记忆、长期知识、外部知识库。
2. 外部知识库是最容易扩展的一层，笔记、文档都可以放进去。
3. 记忆会过期，需要定期复习才会变牢。

## 对我有什么用

以后设计 Agent 的上下文方案时，可以用"三层记忆"这个框架来组织。

## 还没搞懂的地方

三层之间是怎么互相调用的？下次再读一遍验证。
```

## ② 复制下面的空模板，填你自己的

```markdown
# 学习笔记：（标题）

## 我学了什么

（用一两句话说清楚：这一篇讲的核心是什么。）

## 我记下的要点

1. ...
2. ...
3. ...

## 对我有什么用

（这个知识会在什么时候、什么地方用到？）

## 还没搞懂的地方

（写下疑问，下次再读时验证。）
```

## ③ 这份笔记放哪

写完放哪都行，先放在方便的地方。之后确认内容值得长期保留，再把它沉淀成正式知识（wiki）。

> 小技巧：要点不要抄原文，用你自己的话写——"抄下来"和"想明白"是两回事。
