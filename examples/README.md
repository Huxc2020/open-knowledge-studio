# 案例

这里是一组**可以直接复制到你自己知识库**的真实场景。每个场景都告诉你：想实现什么、怎么开始、跑通后是什么样。

## 🚀 第一次来？30 秒看懂怎么用

1. **装好 OKS**（一个命令，见[安装](../docs/installation.md)）。
2. **回来看这个页面**，选一个和你想做的事最像的案例（第一次用就选「托管你的学习」）。
3. **点进案例**，照着里面的「30 秒开始」做——就是把链接甩给 Agent，说"收录"，然后说"晋升"。
4. 完事。以后想用的时候，直接问 OKS 就行。

> 💡 所有案例都是**同一套流程**（收录 → 审核 → 晋升 → 召回），只是"托管的对象"不同。跑通一个，其他就都会了。

## 选一个开始

| 场景 | 适合谁 | 一句话说明 |
|---|---|---|
| [托管你的学习](oh-my-research/) | **第一次用 OKS 的人** | 把看过的文章、课程、书，变成随时能想起来的知识 |
| [托管你的书籍](oh-my-book/) | 技术书读者 | 读过的技术书不再读完就忘，要点可被自动召回 |
| [托管你的飞书](oh-my-feishu/) | 用飞书的团队 | 手机提交、异步采集、IM 里审核一条龙 |
| [托管你的 GitHub](oh-my-github/) | 开源贡献者 | 把技术决策和踩坑沉淀成知识库，反过来驱动贡献 |
| [托管你的开源项目](oh-my-maintainer/) | 项目维护者 | 文档与实现不一致时，怎么发现、修复、沉淀 |
| [托管你的简历](oh-my-resume/) | 求职中的人 | 把经历和成果持续沉淀，投递时一键召回 |

> 💡 **新手提示**：从「托管你的学习」开始——它是为第一次使用 OKS 的人设计的，流程最简单。

## 给维护者

这些目录是**可复制的样例，不是框架的一部分**：

- `assets/` 是产品（打包给每个用户的实例模板）。
- `examples/` 是示范（想用就 copy 到你自己的实例里改）。
- 增加或修改案例不会改变 Core，也不会进入安装包。
- 每个完整场景在自己的目录中说明目标、材料和验收方式；本页只做索引，不维护第二份案例内容。

### 评测数据集

`datasets/recall-v1.example.yaml` **只是格式示例，不能当真值集用**。有意义的评测需要你自己的查询和你自己知识库里的正确答案：

```bash
cp examples/datasets/recall-v1.example.yaml eval/datasets/mine.yaml
# 编辑：query 换成你真的会问的问题，relevant 换成你知道的正确页面
oks eval recall eval/datasets/mine.yaml --output eval/runs/baseline.json
```

### 个人画像与 goal

`goals/`、`projects/`、`users/` 下的内容是**维护者的真实使用记录**，留在这里当范例——展示一个用了几个月的 goal / 画像长什么样，比空模板有参考价值。空模板在 `assets/profiles/` 里，`oks init` 会自动物化到你的实例。
